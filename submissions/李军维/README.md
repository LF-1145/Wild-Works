## 心得体会

本次使用 Codex 辅助搭建环境。我将作业要求发送给Agent ，帮我梳理作业要求，并列出我需要实际上完成的任务。在安装过程中，Agent帮我给出下载安装每一步需要做什么，再由我经过审核确认没有问题之后经由我手进行操作，防止Agent误操作损伤电脑。同时我会把在安装过程出现的报错发送给Agent进行原因解析和后续解决方案。我最初尝试 VirtualBox，但启动虚拟机时多次蓝屏，Agent初步分析是在启用了虚拟化和安全功能的 Windows 11 环境中，VirtualBox 与主机驱动、搜狗输入法或显示组件发生冲突，触发了已有的 Windows 内核不稳定问题，解决较为棘手，因此改为 WSL2 中的 Docker 容器。最后成功搭建ubuntu环境。练习时我曾因不知道自己处在哪个路径中进行操作导致输入相对路径报错、`cd..` 缺少空格而报错，后来学会先用 `pwd` 确认位置，再执行文件操作。总而言之这次练习让我熟悉了ubuntu中一些简单的目录与文件命令，同时也对 Agent 帮助分析和排错的能力有了认知，但是对于电脑的操作还是要自己完成，以防Agent的一些不可控危险操作和读取隐私文件。
